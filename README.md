# THE LAST SORRY — Interactive Apology Story

A clean, cinematic, asset-free Hinglish apology experience. No photos, videos, music or external media files are required.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run
Open `index.html` locally or deploy the folder to GitHub Pages.

## Journey
12 sequential chapters: opening, mirror, heart reconstruction, unsent drafts, feelings, effort meter, promise vault, timeline, apology book, secret vault, letter and finale.

Progress is saved in `localStorage`. The secret vault demo password is `trust`. Edit the Hinglish text directly in `index.html` / `script.js` to personalize it.

## Notes
The site is intentionally independent of photos, videos and audio. Google Fonts are referenced for typography; if offline, the browser falls back to system fonts. For a fully offline build, remove the font import and use the fallback stack.
